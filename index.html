01今日热榜第 1 · TRENDING · PYTHON
MadsLorentzen/ai-job-search
跑在你自己机器上的 AI 求职框架：评估职位、定制简历、写求职信、准备面试，全部基于 Claude Code。
MadsLorentzen / ai-job-search
核心价值
把求职这套重复劳动交给本地 agent，简历与隐私数据不出自己的机器。
主要功能
  • 职位评估：解析招聘信息，输出匹配度评分与差距分析
  • 简历定制：按 JD 改写 CV，突出与职位相关的经历
  • 求职信生成：针对公司与职位自动撰写 cover letter
  • 面试准备：根据 JD 生成面试题与答题要点
应用场景
  • 活跃求职者的批量投递与进度跟进
  • 技术岗位投递前的简历针对性优化
  • 面试前的快速突击准备
  • 求职顾问批量服务多个候选人的模板底座
输入建议
  • 目标职位的完整 JD 文本或链接
  • 一份基础简历（Markdown / PDF 文本）
  • 求职方向与约束（城市、薪资、远程偏好）
使用提醒
  • 生成内容需人工核对，避免经历夸大或失实
  • 本地运行确保简历隐私数据不外泄
  • Fork 后自行调整 prompt 模板以匹配个人风格

DietrichGebert/ponytail
让你的 AI agent 像团队里最懒的资深工程师一样思考——最好的代码是没写的代码。
DietrichGebert / ponytail
核心价值
克制 agent 的过度工程倾向，用最小改动解决问题，减少技术债。
主要功能
  • 极简主义引导：prompt 层约束 agent 优先复用现有代码
  • 反过度设计：抑制不必要的抽象、配置与依赖
  • 面向编码 agent 的行为矫正层
应用场景
  • agent 生成代码冗余度过高的项目
  • 希望减少 AI 味架构的团队
  • 编码 agent 的 prompt 调优参考
输入建议
  • 接入目标 agent（Claude Code 等）
  • 项目代码库
  • 希望约束的具体行为类型
使用提醒
  • 极简不等于质量妥协，关键路径仍需审查
  • 不同 agent 上的效果有差异，需实测
  • 理念型项目，落地需按自身情况调整

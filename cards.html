cloudflare/security-audit-skill
面向编码 agent 的多阶段安全审计 Skill，产出可机读、经独立验证的审计发现。
cloudflare / security-audit-skill
核心价值
把安全审计从人工抽查变成 agent 可重复执行的标准流程，结论可验证、可追踪。
主要功能
  • 多阶段审计流程：分阶段推进而非一次性扫描
  • 机器可读发现：结构化输出便于流转与追踪
  • 独立验证机制：交叉验证降低误报
  • Skill 形态接入 Claude Code 等编码 agent
应用场景
  • 代码库的定期安全自查
  • 上线前的安全门禁检查
  • 安全团队批量审计多个仓库
输入建议
  • 待审计代码库的访问权限
  • 审计范围与关注面（依赖、注入面等）
  • 严重级别阈值与报告格式要求
使用提醒
  • 机器发现仍需安全专家最终复核
  • 审计范围与权限需提前约定
  • 建议先在非关键仓库试跑校准

03本周热榜第 3 · TRENDING · PYTHON
AgriciDaniel/claude-seo
面向 Claude Code 的通用 SEO 技能包：26 个子技能 + 19 个子 agent，覆盖技术 SEO、GEO/AEO 与 Agent 就绪度。
AgriciDaniel / claude-seo
核心价值
把零散的 SEO 实操沉淀成可复用技能，让 Claude 直接产出符合搜索与 AI 抓取规范的内容与报告。
主要功能
  • 26 个子技能 + 19 个子 agent，覆盖技术 SEO、E-E-A-T、schema、GEO/AEO
  • Agent 就绪度：Lighthouse Agentic Browsing、WebMCP、llms.txt
  • 覆盖外链、本地 SEO、电商、国际 SEO 与 Google API
  • 9 个可选扩展接入实时 SEO 数据；支持 PDF/Excel 报告
应用场景
  • 用 Claude 做站点技术 SEO 体检与整改
  • 为内容做 GEO/AEO 与 AI 抓取就绪优化
  • 批量生成 SEO 报告与关键词分析
输入建议
  • 站点地址或待分析内容
  • 关注的 SEO 维度（技术 / 内容 / 外链 / 本地）
  • 可选：Google API 凭据与实时数据扩展
使用提醒
  • 子技能数量多，建议按需启用避免上下文膨胀
  • SEO 结论需结合人工判断，勿盲从自动化建议
  • 实时数据扩展依赖外部 API 配额

06本周热榜第 6 · TRENDING · PYTHON
Graphify-Labs/graphify
把整个代码库连同文档、SQL、配置、PDF 变成可查询知识图谱——Claude Code 等 agent 的建图技能。
Graphify-Labs / graphify
核心价值
让 agent 真正看懂代码库结构：每条关系可解释，且不依赖向量库。
主要功能
  • 全源知识图谱：代码加文档加 SQL 加配置加 PDF 统一建图
  • 本地确定性 AST 解析：不依赖黑盒 embedding
  • 关系可解释：图谱中每条边都有依据
  • 多 agent 技能接入：Claude Code / Cursor / Codex / Gemini CLI
应用场景
  • 大型代码库的架构理解与文档补全
  • 新人上手项目的快速导航
  • agent 编程前的代码库上下文注入
输入建议
  • 代码库路径
  • 需纳入建图的文档与 schema 清单
  • 查询目标（模块关系、调用链等）
使用提醒
  • 超大仓库首次建图耗时较长
  • 图谱查询结果需结合源码核对
  • 语言覆盖以主流编程语言为主

11高增长第 10 · GROWTH · RUST
akitaonrails/ai-memory
为编程类智能体命令行工具提供长期记忆，便于跨会话衔接与上下文移交。
akitaonrails / ai-memory
核心价值
让 agent 记住做过的事与项目背景，减少每次会话从零开始的重复解释。
主要功能
  • 为 agent 编程 CLI 维护长期记忆存储
  • 跨会话保存决策、进度与上下文
  • 支持会话间 handoff（交接）信息
应用场景
  • 长时间项目的多轮开发衔接
  • 多人/多 agent 协作时的上下文传递
  • 中断后快速恢复工作状态
输入建议
  • 被接入的 agent CLI 或项目目录
  • （可选）希望长期保留的要点
使用提醒
  • 记忆需定期清理，避免噪声累积
  • 敏感信息不应明文写入记忆

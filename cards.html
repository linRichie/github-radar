03今日热榜第 3 · TRENDING · SHELL
nvm-sh/nvm
用 bash 脚本在同一台机器上安装与切换多个 Node.js 版本的管理器。
nvm-sh / nvm
核心价值
解决不同项目对 Node 版本的依赖冲突，一键切换运行环境。
主要功能
  • 安装、卸载与列出多个 Node.js 版本
  • 按目录或命令行切换当前版本
  • 支持 .nvmrc 锁定项目版本
  • POSIX 兼容，跨 macOS 与 Linux 使用
应用场景
  • 多项目共用一台开发机、各自要求不同 Node 版本
  • CI 中复现指定 Node 运行环境
  • 快速尝鲜或回退 Node 新版本
输入建议
  • 支持 bash / zsh 的 Unix-like 终端
  • 待管理的项目（可选 .nvmrc）
使用提醒
  • 仅管理 Node 运行时，不处理系统级依赖
  • Windows 需配合 WSL 或 nvm-windows

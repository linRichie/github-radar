thedotmack / claude-mem
核心价值
把 agent 每次会话的上下文沉淀下来，下次自动复用，省去重复交代背景。
主要功能
  • 跨会话持久记忆
  • 自动捕获 agent 操作过程
  • AI 压缩降低上下文体积
  • 智能注入相关历史上下文
  • 兼容 Claude Code、Codex、Gemini、Copilot 等多 agent
应用场景
  • 长期项目的连续开发
  • 多 agent 共享项目背景
  • 减少每次会话的重复铺垫
输入建议
  • 支持的目标 agent 环境
  • 项目文件与工作目录访问
  • 需要记忆保留的范围设置
使用提醒
  • 压缩可能丢失细节，重要信息建议显式标注
  • 注入上下文需防敏感信息泄露

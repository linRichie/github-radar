01今日热榜第 1 · TRENDING · TYPESCRIPT
thedotmack/claude-mem
跨会话的 AI 代理记忆层：自动记录、压缩并回注上下文，让 agent 在多次任务间保持连续认知。
thedotmack / claude-mem
核心价值
让编码代理不再每次从零开始，复用历史会话上下文，减少重复解释、提升长周期任务连贯性。
主要功能
  • 会话捕获：自动记录 agent 每次会话的操作与决策全过程
  • AI 压缩：用模型把冗长记录压缩为可复用上下文摘要
  • 智能回注：在后续会话中按相关性注入对应上下文
  • 多代理兼容：支持 Claude Code、Codex、Gemini、Copilot、OpenCode 等
应用场景
  • 跨多天大型功能开发，保持需求与约束连续性
  • 调试排障时回看此前踩过的坑与已尝试方案
  • 团队共享同一 agent 的工作记忆基线
输入建议
  • 已接入的编码代理及其会话环境
  • 需被记住的项目背景与偏好（会话自然沉淀）
使用提醒
  • 压缩会丢失部分细节，关键决策建议人工确认
  • 回注的上下文可能过时，需结合当前代码状态判断
  • 敏感操作记录注意本地存储与权限隔离

03今日热榜第 3 · TRENDING · RUST
max-sixty/worktrunk
面向并行 AI Agent 工作流的 Git worktree 管理 CLI，让多个 agent 各占独立分支同时开发。
max-sixty / worktrunk
核心价值
把单一仓库拆成多个隔离 worktree，使多个编码 agent 并行干活而不互相踩踏。
主要功能
  • Git worktree 一键创建与清理，避免分支切换冲突
  • 为并行 AI agent 任务分配独立工作目录
  • 轻量 Rust 实现，启动快、无运行时依赖
  • 与常见 agent 编排流程衔接，每个任务一个 trunk
应用场景
  • 多 agent 同时修改同一仓库的不同功能
  • 本地并行运行多个独立重构或补丁任务
  • CI 前在隔离树中预演改动
输入建议
  • 一个已初始化的 Git 仓库
  • 待并行执行的任务清单或 agent 指令
  • 足够的磁盘空间存放多个 worktree
使用提醒
  • worktree 共享同一 .git，误删需谨慎
  • 并行改动仍需人工合并，解决跨 worktree 的冲突

p-e-w/heretic
无需训练的 LLM 修改工具：移除审查、抑制低质内容、减少谄媚等，直接改写模型输出倾向。
p-e-w / heretic
核心价值
不重训模型即可在本地调整语言模型行为，适合研究偏好控制与内容风格实验。
主要功能
  • 训练无关：直接对模型权重或激活做定向修改，无需微调或额外训练
  • 移除审查：关闭模型内置的内容过滤与自我审查机制
  • 抑制 slop：降低套话、模板化、低信息量输出
  • 减少谄媚：削弱无理由附和用户的倾向
应用场景
  • 本地运行开源模型时自定义内容策略
  • 研究模型行为可解释性与偏好偏移
  • 构建不带过度安全护栏的评测与实验环境
输入建议
  • 一个本地可加载的开源语言模型（权重文件或推理后端）
  • 指定的修改配方/目标（如关闭某类审查）
  • 足够的磁盘与显存以加载并改写模型
使用提醒
  • 移除审查后的模型可能产生有害或违规输出，需自行承担合规责任
  • 修改会改变模型原厂对齐行为，不建议直接用于生产面向用户
  • 仅适用于可本地访问权重的开源模型，不作用于闭源 API

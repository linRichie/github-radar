cloudflare/security-audit-skill
面向编码 agent 的多阶段安全审计 Skill，产出可机读、经独立验证的审计发现。
cloudflare / security-audit-skill
核心价值
把安全审计从人工抽查变成 agent 可重复执行的标准流程，结论可验证、可追踪。
主要功能
  • 多阶段审计流程：分阶段推进而非一次性扫描
  • 机器可读发现：结构化输出便于流转与追踪
  • 独立验证机制：交叉验证降低误报
  • Skill 形态接入 Claude Code 等编码 agent
应用场景
  • 代码库的定期安全自查
  • 上线前的安全门禁检查
  • 安全团队批量审计多个仓库
输入建议
  • 待审计代码库的访问权限
  • 审计范围与关注面（依赖、注入面等）
  • 严重级别阈值与报告格式要求
使用提醒
  • 机器发现仍需安全专家最终复核
  • 审计范围与权限需提前约定
  • 建议先在非关键仓库试跑校准

stablyai/orca
一个平台统管你的 agent 舰队：用自有订阅运行任意编码 agent，支持桌面、移动与远程运行时。
stablyai / orca

用自己的 Claude Code 等订阅驱动多个 agent，不必为每个工具单独付费。

  • 跨端可用：桌面、移动端与远程运行时
应用场景

输入建议

  • 凭证托管需评估对该平台的信任
  • 订阅条款需确认允许多客户端使用
  • 远程运行时注意网络与访问控制

03今日热榜第 4 · TRENDING · PYTHON
headroomlabs-ai/headroom
在内容进入 LLM 之前先压缩：编码 agent 省两成 token，JSON 场景省六到九成，答案不变。
headroomlabs-ai / headroom
核心价值
直接砍 token 账单——同样的答案，几分之一的成本。
主要功能
  • 预压缩：工具输出、日志、文件、RAG 分块进 LLM 前先瘦身
  • JSON 场景最高省 95% token
  • 三种形态：库 / 代理 / MCP server
应用场景
  • 高频调用 LLM 的成本优化
  • RAG 管道的上下文瘦身
  • coding agent 的 token 预算管理
输入建议
  • 待压缩的内容源（工具输出 / 日志 / RAG 分块）
  • 部署形态选择（library / proxy / MCP）
  • 可接受的质量损失阈值
使用提醒
  • 极端压缩可能影响精确代码生成等细节任务
  • 建议先在自己的工作负载上实测压缩率
  • 有损程度需按场景权衡

04今日热榜第 5 · TRENDING · JAVASCRIPT
DietrichGebert/ponytail
让你的 AI agent 像团队里最懒的资深工程师一样思考——最好的代码是没写的代码。
DietrichGebert / ponytail
核心价值
克制 agent 的过度工程倾向，用最小改动解决问题，减少技术债。
主要功能
  • 极简主义引导：prompt 层约束 agent 优先复用现有代码
  • 反过度设计：抑制不必要的抽象、配置与依赖
  • 面向编码 agent 的行为矫正层
应用场景
  • agent 生成代码冗余度过高的项目
  • 希望减少 AI 味架构的团队
  • 编码 agent 的 prompt 调优参考
输入建议
  • 接入目标 agent（Claude Code 等）
  • 项目代码库
  • 希望约束的具体行为类型
使用提醒
  • 极简不等于质量妥协，关键路径仍需审查
  • 不同 agent 上的效果有差异，需实测
  • 理念型项目，落地需按自身情况调整

shiyu-coder/Kronos
面向金融市场语言训练的基础模型：专攻金融领域的术语、行情与研报文本理解。
shiyu-coder / Kronos
核心价值
为金融场景提供通用的语言理解底座，降低金融 NLP 任务的冷启动成本。
主要功能
  • 金融领域预训练语言模型基座
  • 面向金融术语与行情表述的语义理解
  • 可微调用于研报、公告、新闻等金融文本任务
  • 基于 Python 生态，便于接入现有推理流水线
应用场景
  • 研报、财报、公告的自动摘要与信息抽取
  • 金融新闻与舆情文本分类
  • 行情快讯的结构化解析
  • 金融问答或投研助手的底模 / 文本嵌入来源
输入建议
  • 金融文本语料（研报、新闻、公告、行情快讯）
  • 具体下游任务定义与少量标注样本
  • 目标部署环境（推理算力与框架约束）
使用提醒
  • 金融预测存在固有不确定性，模型输出不构成投资建议
  • 基础模型能力取决于预训练语料覆盖，建议结合自有数据微调
  • 落地前请核对开源许可证与金融数据合规要求

07高增长第 4 · GROWTH · PYTHON
Graphify-Labs/graphify
把整个代码库连同文档、SQL、配置、PDF 变成可查询知识图谱——Claude Code 等 agent 的建图技能。
Graphify-Labs / graphify
核心价值
让 agent 真正看懂代码库结构：每条关系可解释，且不依赖向量库。
主要功能
  • 全源知识图谱：代码加文档加 SQL 加配置加 PDF 统一建图
  • 本地确定性 AST 解析：不依赖黑盒 embedding
  • 关系可解释：图谱中每条边都有依据
  • 多 agent 技能接入：Claude Code / Cursor / Codex / Gemini CLI
应用场景
  • 大型代码库的架构理解与文档补全
  • 新人上手项目的快速导航
  • agent 编程前的代码库上下文注入
输入建议
  • 代码库路径
  • 需纳入建图的文档与 schema 清单
  • 查询目标（模块关系、调用链等）
使用提醒
  • 超大仓库首次建图耗时较长
  • 图谱查询结果需结合源码核对
  • 语言覆盖以主流编程语言为主
